How this is measured

The per-epoch icons on a solana.org validator page map one-to-one onto the epoch state values returned by the Solana Foundation API. This page aggregates those states directly.

stateIcon on solana.orgTreated here as
BonusGreen starMet
BaselineOrange checkNot counted as a miss — matching unmet but residual met. Counted in the not_bonus rate.
NoneRed XMiss
NoneHighThirdPartyStakeGreen party popperMet — third-party stake is high enough that no SFDP stake is needed

Miss rate = None epochs ÷ epochs with data. not_bonus rate = (None + Baseline) ÷ epochs with data. Streak = consecutive misses ending at the most recent epoch. Miss rates of 20% or higher are shown in red, 10% or higher in yellow. Epochs absent from the API are treated as pre-onboarding or delinquent and excluded from the denominator. Newly onboarded validators have a small denominator, so by default only validators with data for at least half the window are shown.
